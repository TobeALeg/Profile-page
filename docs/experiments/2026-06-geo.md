## 已确认的经历

GEO 是公司要求做的项目。最开始用 Claude Code 开发，是无头的，没有图形界面。当时只是为了确认业务流程能跑通。

后来需要向客户证明我们有这个产品，拿出去介绍，才用 Codex 做界面。界面不是一次补齐的，而是一点一点做起来的。

再后来，真正需要用它进行 GEO 的规划、管理和发布。mentti、Probe、Post 等工具以及插件，都是在这个过程中逐渐产生的。这是一点一点自动化的过程。

工具切换及开发动机来自本人叙述；提交记录只支持功能与代码时间，不据此反推工具或动机。

## 时间线文案草稿

### 先跑通，再展示，最后真正用起来

公司要求做 GEO 时，我先用 Claude Code 搭了一套没有图形界面的流程。当时的目标很直接：确认这件事能跑通。

后来，我们需要拿出去向客户介绍，证明我们有这个产品，于是开始用 Codex 做界面。那时，界面首先承担的是展示和讲解的作用。

再后来，我们真正开始用它做 GEO 的规划、管理和发布。实际工作里的需求不断出现，界面和功能也跟着一点点补齐。mentti、Probe、Post，以及插件，都是在这个过程中逐渐发展出来的。

它是一个在使用中，把越来越多的工作逐步自动化的过程。
