## 已确定的方向

栏目名称为 AI Experiments，展示真实工作中的 AI 探索，按从新到旧的时间线排列，最新节点在最上方。重点是本人的思考、方法变化和进步，项目与不同阶段的 UI 是证据。持续迭代的项目可以跨越多个时间节点。

每个案例独立保存 Markdown。本人叙述、仓库证据、编辑建议和待补问题分开记录；记不清的部分不补猜。讨论得到新的具体信息后及时更新对应文件。
