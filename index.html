2026.08

Dashboard：看效果，再收敛设计

把入口提示放进标题；把应用入口与身份配置收进同一个对象。

内部工具通过长按标题展开。我先要求在标题旁加按压按钮，看过效果后改成标题文字自身的动效，再调整字体、周期和下压节奏。另一个点是动态接入：拿到同事项目的部署地址后，在管理页维护入口，再逐步合并应用和身份配置。

长按控制的是展示分组，不是安全权限。目录管理不会替目标应用完成部署、登录或权限适配。

GEO：先有事实，再让内容有目的

先搞清楚内容服务谁，再让界面与自动化服务这些判断。

公司要求做 GEO 时，我先用 Claude Code 验证无头流程。内容要基于客户资料，以及客户对产品和客户的认知。之后，我花了很长时间理解内容的服务对象和目的，形成方法论与场景包：既解释商业问题，也说明每篇文章希望产生什么影响。后来才用 Codex 逐步做出客户展示和实际运营的界面。

事实基础 → 服务对象 → 方法论与场景包 → 界面 → 自动化判断

Post 围绕同一份稿件管理版本与发布记录；发布插件采用半自动方式，保留人工确认。实现记录不等于已合并、已上线或已验证内容效果。
