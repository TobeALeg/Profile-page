WORKET

macOS arm64 · 本地常驻工作记录 TobeALeg/worket ↗
“工作应当存续于执行它的 Agent 之外。”

Worket 是一个本地 macOS 工作记录工具。识别前台 Codex 或 WorkBuddy 工作上下文，把可见 Prompt、回复、工具记录与资料引用整理成独立的 WorkInstance / WorkRecord，并可交给另一端继续。

持久实体：Persistent Work, Context, State, Artifacts
执行解耦：Executor（执行模型）只是可随时热替换的执行环境
探索 Worket 细节 → 架构文档 ↗
TOPOLOGY // PIPELINE SCHEMATIC 解耦执行架构
Context Prompts & 引用
State 目标与进度
Artifacts 文件与产物

脱离特定模型生命周期 · 跨会话/跨工具长久存续
│ ▼ 分发至目标执行宿主
